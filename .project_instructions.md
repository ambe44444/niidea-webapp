# NiIdea — Planes sorpresa en Madrid

## Overview
Plataforma de experiencias sorpresa en Madrid. Los usuarios compran un plan sin saber qué es, eligen fecha/personas/nivel, pagan con Stripe, y reciben los detalles por email el día antes.

## Tech Stack
- Next.js 16 (App Router) + React 19 + Tailwind CSS 3
- Prisma ORM + PostgreSQL (external DB)
- Stripe (checkout + webhooks)
- Custom admin auth via signed cookies (no next-auth)
- Email notifications via Abacus notification API
- Twilio WhatsApp (placeholder credentials)

## Key Architecture
- **Auth**: Custom cookie-based admin auth in `lib/admin-auth.ts` — all functions are `async` (Next.js 16 cookies() is async)
- **DB**: External PostgreSQL, DATABASE_URL in .env. Tables: orders, experiences, reviews
- **Stripe**: Live keys configured. Webhook endpoint: `/api/webhooks/stripe`
- **Cron**: `/api/cron/send-today` protected by CRON_SECRET header — sends plan reveals to customers
- **Admin**: `/admin` page with password-based login

## Color Palette
- Background: `#0B0B0B` (near-black)
- Accent: `#FFD54F` (gold/yellow)
- Text: white with varying opacity
- Dark theme only

## Important Notes
- All admin-auth functions (isAdminAuthenticated, setAdminSession, clearAdminSession) are async — always await them
- Params in dynamic routes are `Promise<{ id: string }>` — must be awaited
- The app uses `font-script` (Caveat) for the logo and `font-sans` (Inter) for body text
- Stripe webhook secret needs to be updated after deployment to point to new URL
